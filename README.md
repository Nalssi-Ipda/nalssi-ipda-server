# nalssi-ipda-server

## 개요
사용자에게 날씨를 매일 아침 7시 사용자의 핸드폰에 알림 배너를 띄워주는 앱을 만든다
### 목적
1. 매일 아침 7시 사용자의 핸드폰에 알림 배너를 띄워주자(알림 배너 특성상 계속 떠있음)
### 특징
1. 앱의 특성을 부여하자
    1. 알림의 내용을 패션에 관련된 내용을 추가해서 보내주면 어떨까?
        1. ex. 오늘 날씨는 5도예요~ 선선한 날씨니 얇은 겉옷을 챙기는건 어떨까요??
        2. ex. 오늘의 날씨는 2도예요~ 비가 예보되어있으니 우산을 챙기는건 어떨까요?
           앱의 특성을 부여해 패션 커머스 앱을 만드는 건 어떨까?
           -> 근데 너무 커머스에 포커스가 맞춰지는것은 아닌가..
           적절한 선은 어디에 있나?
           근데 저기에 뭘 넣을려면 해당 (광고)라는 문구가 필요하지 않은가?



## 프로젝트 컨벤션
### Commit  컨벤션
```text
<타입>: <내용>
```
### Branch 컨벤션
모든 작업에 대해 시작시 브랜치를 생성해서 작업을 진행합니다

브랜치 명명 규칙
```text
<타입>/<이슈번호>-<간단한-설명(영문 소문자, 하이픈 구분)>
```

#### 브랜치 타입
```text
feat/                   → 새 기능 개발
fix/                    → 버그 수정
hotfix/                 → 프로덕션 긴급 수정
refactor/               → 리팩토링 (기능 변화 없음)
chore/                  → 빌드설정, 패키지 업데이트 등 잡무
docs/                   → 문서 수정
test/                   → 테스트 코드 추가/수정
```
