# nalssi-ipda-server



## 프로젝트 컨벤션
### Commit  컨벤션
```text
<타입>: <내용>
```
### Branch 컨벤션
모든 작업에 대해 시작시 브랜치를 생성해서 작업을 진행합니다

브랜치 명명 규칙
```text
<타입>/<이슈번호>-<간단한-설명(영문 소문자, 하이픈 구분)>
```

#### 브랜치 타입
```text
feat/                   → 새 기능 개발
fix/                    → 버그 수정
hotfix/                 → 프로덕션 긴급 수정
refactor/               → 리팩토링 (기능 변화 없음)
chore/                  → 빌드설정, 패키지 업데이트 등 잡무
docs/                   → 문서 수정
test/                   → 테스트 코드 추가/수정
```
